One dense newspaper front page summing up the world news of Thursday
19 November 2026: the Shenzhen trilateral of Trump, Xi and Putin, the
record Anthropic IPO, GTA VI launch day, and 39 more verified stories
across every region and field, with a UTC timeline and a date check.
See MODEL.md for every story, its source outlet, and what was excluded.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This renders the front page with `draw_frontpage.py` (PIL) and copies
`entry.png` to the output directory, verifying the copy byte for byte.
To re-render the image from scratch:

```sh
python3 draw_frontpage.py
```
